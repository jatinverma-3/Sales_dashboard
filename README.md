* GLOBAL SALES DASHBOARD

The Sales Dashboard is designed to provide clear insights into business performance through data visualization. It displays key metrics such as revenue, profit, and top-selling products using an interactive and user-friendly interface.

A dynamic dashboard built in Power BI, it showcases monthly trends, regional sales, and product-wise analysis, helping businesses make informed decisions. This project ensures smooth understanding of sales data by transforming raw numbers into meaningful visuals for stakeholders.
